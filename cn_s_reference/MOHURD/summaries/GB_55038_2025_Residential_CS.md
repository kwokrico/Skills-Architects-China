# GB 55038-2025 Residential project code (住宅项目规范)

**Architect critical summary for schematic design**

MOHURD Announcement 2025 No. 39, issued 2025-03-13, in force 2025-05-01. Mandatory residential project code. | Ministry of Housing and Urban-Rural Development

> Scope note: This is an architect's digest for routing and early design. It is not the text of the law or standard. Confirm every number, clause, and edition in the official publication before design, tender, or submission.

## Regulatory Overview

GB 55038-2025 is the mandatory floor for a residential project. Where an older residential or environmental standard conflicts, this code prevails. The code text is the attachment to the announcement. This digest does not copy those articles, and it does not record a storey height, door width, lift threshold, or sound rating.

## Critical topics

- Check project transition and the approval date before applying this code to a scheme that was permitted earlier. The announcement does not itself grant a blanket exemption.
- The announcement repeals GB 50368-2005 住宅建筑规范 in full.
- The announcement repeals GB 50033-2013 clause 4.0.1. Do not reuse that daylight clause for a residential room.
- The announcement repeals GB 50118-2010 clauses 4.2.1, 4.2.2, and 4.2.5. Do not reuse those residential sound clauses.
- The announcement also repeals named mandatory clauses of GB 50096-2011, GB 50327-2001, GB 50631-2010, JGJ 242-2011, JGJ 367-2015, and JGJ 286-2013. Open the announcement for that clause list before using any of those standards on housing.
- Sunlight spacing remains a GB 50180 plus city-rule question. Room daylight remains GB 55016, then GB 50033 only where it still applies. Do not swap them.

## Schematic-design takeaway

Open the code PDF on the announcement page before quoting a residential minimum. This file only records what the announcement repealed.
