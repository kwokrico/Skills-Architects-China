# Human-Scale Dimensions (Mainland Coordination)

Coordination defaults for early layout. They are not quotations from a clause. Before issue, check GB 55019-2021 (mandatory access floor), GB 50763 where it does not conflict, and GB 55031 for stairs, corridors, and sanitary rooms. Anthropometric source data are in GB 10000; confirm the edition on the standards catalogue before citing a percentile.

| Item | Coordination default | Verify in |
|------|----------------------|-----------|
| Clear door width, public entrance | Allow a wheelchair user; do not assume 900 mm is always enough | GB 55019 / GB 50763 |
| Corridor clear width, public | Wider than a residential unit corridor | GB 55031 and GB 55019 |
| Ramp | Slope, landings, and handrails are mandatory-code items | GB 55019 |
| Stair riser and going | Follow GB 55031; do not import a Hong Kong regulation figure | GB 55031 |
| Handrail height | Follow the access and stair clauses actually in force | GB 55019 / GB 55031 |
| Accessible toilet | Turning space and door swing; room size is not a single national number in this note | GB 50763 |
| Lift car | Accessible car dimensions and controls | GB 55019 and the lift product standard |
| Tactile paving | Location and contrast at public paths | GB 50763 and the local streetscape guide |
| Counter and switch height | Reach range for a seated user | GB 50763 |
| Refuge | Where a refuge is required is a fire-code question | GB 55037, not this note |

## Rules

- State the code edition in the drawing note.
- A furniture layout at 1:100 is not an access audit.
- Residential, school, hospital, and transport uses add their own JGJ or project codes. Load `cn-accessibility-design` and `cn-building-typology`.
- If a dimension is not in the project code set, mark it unverified. Do not fill the gap from memory.
