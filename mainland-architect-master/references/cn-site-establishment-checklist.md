# Site Establishment Checklist — Mainland

Reference for `cn-site-establishment`. Complete before main works.

---

## Permits and Statutory

- [ ] 施工许可证 公示
- [ ] 质安监 监督登记
- [ ] 开工条件检查 / 开工报告（视地方）
- [ ] 审图合格书 与 FOR CONSTRUCTION 图纸一致

---

## Site Works

- [ ] 三通一平 完成范围界定
- [ ] 围蔽方案 报批/备案
- [ ] 占道施工许可（如需要）
- [ ] 临时用电用水 接驳
- [ ] 塔吊/施工电梯 方案与检测计划

---

## Utilities and Telecom

- [ ] 市政管线 迁改计划
- [ ] 三大运营商 管线查明与保护协议 → `cn-telecom-coordination`
- [ ] 临时排水与沉淀池

---

## Interfaces

- [ ] 交警 施工交通组织意见 → `cn-traffic-coordination`
- [ ] 邻居公示 与投诉渠道
- [ ] 监理 组织架构到岗
