# Heritage impact assessment starter checklist (Mainland China)

Use for 文物、历史建筑、历史文化街区、风貌保护类项目的启动核对。

| Item | Check | Notes |
|------|-------|-------|
| Protection category | 全国重点 / 省级 / 市级 / 历史建筑 | 确定审批路径 |
| Control plan | 保护规划、建设控制地带 | 与 控规 一致性 |
| Massing | 高度、体量、风貌协调 | 方案阶段预沟通 |
| Materials | 传统工艺与可识别性 | 修缮 vs 改建边界 |
| MEP intrusion | 设备对风貌的影响 | 隐蔽化策略 |
| Authority | 文物/住建/规自分工 | 城市差异大 |

**Assumption:** 以项目所在地主管部门最新名录和批复为准。
