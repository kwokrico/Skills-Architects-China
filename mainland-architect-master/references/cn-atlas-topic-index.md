# 图集 topic index

A 图集 shows a construction method. It does not discharge a mandatory clause. Cite the clause first, then the atlas number as the detail source. A keyword match is not a code citation.

Numbers below were listed as 现行 on the China Institute of Building Standard Design catalogue (chinabuilding.com.cn book library) when this index was written. Confirm the number again before issue. Withdrawn numbers are not details.

| Topic | Atlas to open | Confirm before issue |
|---|---|---|
| 平屋面 | 12J201 平屋面建筑构造 | Still current, and the roof type is a flat roof. Pitched roofs: 09J202-1. Planted roofs: 14J206 |
| 地下防水 | 10J301 地下建筑防水构造 | Still current. The mandatory floor is GB 55030, not the drawing |
| 变形缝 | 14J936 变形缝建筑构造 | Still current. Fire and waterproof strips in the detail do not replace the fire or waterproofing clause |
| 楼梯 | 22J403-1 楼梯 栏杆 栏板（一） | Still current. 15J403-1 is the edition it replaced. Stair dimensions still come from GB 55031 |
| 无障碍 | 12J926 无障碍设计 | Still current. 03J926 is withdrawn. The mandatory floor is GB 55019 |
| 防火构造 | 07J905-1 防火建筑构造（一） | Still current, and still consistent with GB 55037. Do not use a product 图集 (a CJ number tied to one manufacturer) as the project default |
| 幕墙 | No single current generic glass-curtain-wall volume | The 2003 建筑幕墙合订本 (J103-2～7) is withdrawn. Double-skin: 07J103-8. Artificial-board cladding: 13J103-7. For any other system, look up the current number on the catalogue. Facade fire class still comes from GB 55037 |

Illustration volumes of an older fire code, including 18J811-1, do not override GB 55037.
