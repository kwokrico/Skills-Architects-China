## City hook

A local conclusion needs the current provincial or municipal edition. Ask for it. Do not reuse a number from another city.

| City or region | Series to ask for |
|---|---|
| Beijing | DB11 |
| Shanghai | DGJ08 |
| Shenzhen | The current Shenzhen SJG or municipal building code edition |
| Guangdong | The current DBJ edition for the city |
| Other cities | The current DB, DGJ, or DBJ edition named in the planning permit or 审图意见 |

National baseline still applies when the city edition is missing. Say so.
